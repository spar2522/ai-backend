ai-backend

FastAPI backend engineering project.

Create Environment

uv venv
source .venv/bin/activate

Install FastAPI

uv pip install fastapi uvicorn

Run Server

uvicorn main:app --reload

URLs

http://127.0.0.1:8000
http://127.0.0.1:8000/docs

Example Dynamic Route

@app.get("/hello/{name}")
def hello(name: str):
    return {"message": f"Hello {name}"}

Example POST API

class ChatRequest(BaseModel):
    message: str

@app.post("/chat")
def chat(req: ChatRequest):
    return {
        "reply": f"You said: {req.message}"
    }
Mental Model: FastAPI = framework, uvicorn = server runtime, nginx = traffic layer.
