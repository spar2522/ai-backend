PostgreSQL + Docker Reference

1. Start PostgreSQL Container

docker run --name postgres-demo \
  -e POSTGRES_PASSWORD=password \
  -e POSTGRES_USER=admin \
  -e POSTGRES_DB=ai_backend \
  -p 5432:5432 \
  -d postgres
Mental Model: Docker container = isolated PostgreSQL database server running locally.

2. Check Running Containers

docker ps

3. Restart Existing Database Container

docker start postgres-demo

Use this after rebooting machine or after stopping the DB.

4. Stop Database

docker stop postgres-demo

5. Open PostgreSQL Shell

docker exec -it postgres-demo psql -U admin -d ai_backend

6. Useful PostgreSQL Commands

List Tables

\dt

Create Table

CREATE TABLE chats (
    id SERIAL PRIMARY KEY,
    message TEXT
);

Insert Data

INSERT INTO chats (message)
VALUES ('Hello PostgreSQL');

Read Data

SELECT * FROM chats;

7. Delete Container

docker rm -f postgres-demo

Warning: Removes the container completely.

8. Key Mental Models

  • Database = persistent state
  • Containers are isolated infrastructure services
  • AI systems need memory and persistence
  • FastAPI will later connect to PostgreSQL
  • Most modern AI systems are orchestration + database systems
